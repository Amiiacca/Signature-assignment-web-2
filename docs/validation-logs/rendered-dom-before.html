Automated checks

Runs all three routes plus two error cases and checks each response.

  • GET /api/adoptions returns a non-empty array sorted by AdoptionDate
  • GET /api/adoptions/14 returns the adoption with AdoptionID 14
  • GET /api/adoptions/university/100724 returns only UniversityID 100724
  • GET /api/adoptions/9999 returns 404 for a missing adoption
  • GET /api/adoptions/abc returns 400 for a non-numeric id
